## Level 2: Calculation Problems

### 2.1 Magnitude Calculations

**Q2.1.1:** Find the magnitude of the following vectors:
- (a) v = 3î + 4ĵ
- (b) v = 1î + 2ĵ + 2k̂
- (c) v = 5î - 12ĵ
- (d) v = î + ĵ + k̂

**Answers:**
- (a) 5
- (b) 3
- (c) 13
- (d) √3

---

**Q2.1.2:** If |v| = 10 and v = 6î + bĵ, find b.

**Solution:**
|v|² = 36 + b² = 100
b² = 64
b = ±8

---

**Q2.1.3:** Vector AB has magnitude 13. If A = (1, 2) and B = (x, 14), find x.

**Solution:**
AB = (x-1)î + 12ĵ
|AB|² = (x-1)² + 144 = 169
(x-1)² = 25
x-1 = ±5
x = 6 or x = -4

### 2.2 Unit Vector Problems

**Q2.2.1:** Find unit vectors in the direction of:
- (a) v = 3î + 4ĵ
- (b) v = 2î - 2ĵ + 1k̂
- (c) Position vector of point P(1, 2, 3)

**Answers:**
- (a) (3/5)î + (4/5)ĵ
- (b) (2/3)î - (2/3)ĵ + (1/3)k̂
- (c) (1/√14)î + (2/√14)ĵ + (3/√14)k̂

---

**Q2.2.2:** If û is a unit vector and û = aî + (a+1)ĵ, find a.

**Solution:**
|û|² = a² + (a+1)² = 1
a² + a² + 2a + 1 = 1
2a² + 2a = 0
2a(a + 1) = 0
a = 0 or a = -1

**Check:**
- If a = 0: û = 0î + 1ĵ (unit vector ✓)
- If a = -1: û = -1î + 0ĵ (unit vector ✓)

### 2.3 Direction Cosines

**Q2.3.1:** Find direction cosines of:
- (a) v = 1î + 2ĵ + 2k̂
- (b) v = 2î - 1ĵ + 2k̂
- (c) Ratio (1, 1, 1)

**Answers:**
- (a) l = 1/3, m = 2/3, n = 2/3
- (b) l = 2/3, m = -1/3, n = 2/3
- (c) l = 1/√3, m = 1/√3, n = 1/√3

---

**Q2.3.2:** Direction cosines are (l, m, n). If l = 1/2 and m = 1/2, find n.

**Solution:**
l² + m² + n² = 1
(1/4) + (1/4) + n² = 1
n² = 1/2
n = ±1/√2

---

**Q2.3.3:** Convert direction ratios (2, -2, 1) to direction cosines.

**Solution:**
Magnitude = √(4 + 4 + 1) = 3
Direction cosines: l = 2/3, m = -2/3, n = 1/3

## Level 3: Application Problems

### 3.1 Geometry Applications

**Q3.1.1:** Prove that points A(1, 2, 3), B(2, 3, 4), and C(3, 4, 5) are collinear.

**Solution:**
AB = 1î + 1ĵ + 1k̂
AC = 2î + 2ĵ + 2k̂
AC = 2·AB
Therefore, AB and AC are parallel and share point A.
Hence A, B, C are collinear. ✓

---

**Q3.1.2:** Show that ABCD is a parallelogram where:
A(0, 0, 0), B(1, 2, 3), C(2, 3, 4), D(1, 1, 1)

**Solution:**
AB = 1î + 2ĵ + 3k̂
DC = C - D = (2-1)î + (3-1)ĵ + (4-1)k̂ = 1î + 2ĵ + 3k̂
AB = DC ✓

AD = 1î + 1ĵ + 1k̂
BC = C - B = (2-1)î + (3-2)ĵ + (4-3)k̂ = 1î + 1ĵ + 1k̂
AD = BC ✓

Therefore ABCD is a parallelogram. ✓

### 3.2 Physics Applications

**Q3.2.1:** Three forces act at a point O:
- F₁ = 3î N
- F₂ = 4ĵ N
- F₃ = 5k̂ N

Find the magnitude of resultant force.

**Solution:**
F_net = F₁ + F₂ + F₃ = 3î + 4ĵ + 5k̂
|F_net| = √(9 + 16 + 25) = √50 = 5√2 N

---

**Q3.2.2:** A particle moves from A(1, 2) to B(4, 6). Express the displacement vector and find distance traveled (assuming straight line).

**Solution:**
Displacement = AB = 3î + 4ĵ
Distance = |AB| = √(9 + 16) = 5 units

### 3.3 Mixed Problems

**Q3.3.1:** If P divides AB in ratio 2:1 internally, and A(1, 2, 3), B(7, 8, 9), find:
- (a) Position vector of P
- (b) Coordinates of P
- (c) Distance |AP| and |PB|

**Solution:**
Using section formula: P = (1·B + 2·A)/(2+1) = (1·(7,8,9) + 2·(1,2,3))/3

P = ((7+2)/3, (8+4)/3, (9+6)/3) = (3, 4, 5)

(a) Position vector: 3î + 4ĵ + 5k̂
(b) Coordinates: P(3, 4, 5)
(c) |AP| = √((3-1)² + (4-2)² + (5-3)²) = √12 = 2√3
    |PB| = √((7-3)² + (8-4)² + (9-5)²) = √48 = 4√3
    Ratio: |AP|:|PB| = 2√3 : 4√3 = 1:2 ✓ (Note: should be 2:1 as given)

## Level 4: JEE Advanced Level

### 4.1 Complex Problems

**Q4.1.1:** If a, b, c are direction ratios of a line, and the line passes through P(1, 2, 3) with direction (1, 2, 2), find:
- (a) Direction cosines
- (b) The general point on the line
- (c) Point at distance 6 from P along the line

**Solution:**
(a) Direction ratios: (1, 2, 2)
    ||(1,2,2)|| = √(1+4+4) = 3
    Direction cosines: (1/3, 2/3, 2/3)

(b) General point: (1+t, 2+2t, 3+2t) where t is parameter

(c) Distance = 6, so |t|·√(1+4+4) = 6
    |t|·3 = 6
    t = ±2
    Point 1: (3, 6, 7) [when t = 2]
    Point 2: (-1, -2, -1) [when t = -2]

### 4.2 Proof-Based Questions

**Q4.2.1:** Prove that direction cosines are unique for any direction.

**Proof:**
Consider direction cosines (l, m, n) for a direction.
They satisfy: l² + m² + n² = 1
Also: l = cos α, m = cos β, n = cos γ where α, β, γ are angles with coordinate axes.
Since cosine function is single-valued for angles in [0, π],
each direction uniquely determines l, m, n.
Conversely, given l, m, n satisfying the constraint,
the direction is unique (up to orientation).
Hence direction cosines are unique. ✓
